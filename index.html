How a fax leaves this house
The PDF is rendered to a Group-4 TIFF and Asterisk dials the number on the voipms-fax trunk view with SendFax(…,f): plain G.711 audio, because VoIP.ms never accepts the T.38 switch (measured 2026-09-27; without f the call aborts). A call marked ANSWERED is not a delivered fax — the outcome column comes from the fax counters. The Canon MX922 still works too: dial 8 + 1 + number from it. All of this is the fax CLI (~/Projects/fax); this panel only calls it.
/usr/local/bin/fax --local --json send <pdf> <number>
